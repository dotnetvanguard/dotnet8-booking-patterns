# .NET 8 Booking Service Patterns

Practical examples and architecture notes for
building reliable booking and reservation services
using modern .NET technologies.

## Technology Stack

- C# and .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- Dapper
- PostgreSQL
- Redis
- Azure Service Bus
- Azure Functions
- Docker

## Architecture Topics

### REST API Design
- Request validation
- Error handling
- API versioning
- OAuth 2.0 and JWT authentication

### Booking Reliability
- Idempotent reservation requests
- Transaction management
- Concurrent booking prevention
- Retry and timeout handling

### Event-Driven Messaging
- Booking confirmation events
- Background processing
- Dead-letter queues
- Reliable notification delivery

## Project Goal

Explore practical patterns for building secure,
maintainable, and scalable .NET backend services.

This repository contains independent examples
and engineering documentation.
