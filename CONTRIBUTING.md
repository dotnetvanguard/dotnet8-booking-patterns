# Contributing Guidelines

Thanks for contributing!

## Development Standards

- Use .NET 8 and modern C# conventions.
- Follow SOLID design principles.
- Prefer dependency injection.
- Keep API controllers lightweight.
- Use asynchronous APIs appropriately.

## Database Guidelines

- Use parameterized SQL queries.
- Review migrations carefully.
- Add indexes based on query patterns.
- Handle transactions explicitly.

## Testing

- Write xUnit tests.
- Cover validation and failure scenarios.
- Test idempotency behavior.
- Verify database transaction boundaries.

## Pull Requests

1. Create a feature branch.
2. Implement the change.
3. Add or update tests.
4. Document API changes.
5. Submit a pull request.
